# Hinge-Style Dating App Prototype

A modern dating app prototype inspired by Hinge, featuring profile cards with prompts, matching functionality, and real-time messaging.

## Features

- **Profile Discovery**: Browse through user profiles with photos and personality prompts
- **Hinge-Style Prompts**: Users answer creative questions like "My simple pleasures", "Two truths and a lie", etc.
- **Interactive Actions**:
  - ❤️ Like profiles
  - 💬 Comment on specific prompts
  - ✕ Pass on profiles
- **Smart Matching**: Get matched with users who like you back
- **Real-Time Chat**: Message your matches with a clean, intuitive interface
- **Responsive Design**: Works seamlessly on desktop and mobile devices

## How to Use

1. Open `index.html` in your web browser
2. Browse profiles by scrolling through the profile cards
3. Click on prompts to leave a comment, or use the action buttons:
   - Click ❤️ to like
   - Click 💬 to comment
   - Click ✕ to pass
4. Navigate between tabs:
   - 🔥 **Discover**: Browse new profiles
   - 💬 **Matches**: View and chat with your matches
   - ❤️ **Likes**: See who you've liked
